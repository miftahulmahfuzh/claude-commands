## Goal

After this phase, `plan_graph.py` resolves a plan set's phase plans inside a **linked git
worktree** — the layout `/analyze` always produces — so the write-set gate reports real write
sets and exits `0`/`2` instead of silently exiting `1` while printing "no file is written by two
phases". And when a write set is unknown for *any* reason, the gate now says so rather than
printing that sentence: "no collision was found" and "no collision exists" are different
statements, and only the first is true over a partial analysis. A path that two phases declare with different actions takes the **most severe** class
rather than the lower-numbered phase's, so a generated or binary artifact can no longer be
downgraded to ISOLATE by phase numbering. And `skills/swarm/tests/` exists: a stdlib-only,
self-contained regression harness that builds real repos and real worktrees, and that **fails

## Why this root-finder (R1)

The decision is already made in the plan index's `## Decisions` table (rung 6) and this phase
implements it rather than re-litigating it. What follows is the *justification the user asked
for*, confirmed by measurement this session:

```
$ file <worktree>/.git
<worktree>/.git: ASCII text          # a `gitdir:` pointer, not a directory
$ git -C <worktree>/docs/plans rev-parse --show-toplevel
<worktree>                           # correct, from a subdirectory, in a linked worktree
$ git -C <somewhere-outside-a-repo> rev-parse --show-toplevel
fatal: not a git repository ...      # non-zero -> swarm.py's git() returns None
```

`git rev-parse --show-toplevel` handles the linked worktree, the main checkout and a submodule
uniformly, and it is **house style**: `swarm.py:161 main_worktree()` already shells to git for the
same class of question, and `swarm.py:107 git()` already maps both a missing binary (`OSError`)
and a non-zero exit to `None`, which is exactly invariant 4's "degrade, never raise". `plan_graph`
already imports from `swarm` at line 27, so this adds a name, not a dependency.

**cwd matters and is easy to get wrong.** `git()` is called with `cwd = the index file's
directory`, never the process cwd: `/analyze-orchestrator` runs the gate from wherever the
coordinator happens to be sitting, which is frequently a *different repository*. Measured: with
the fix in place and cwd set to `/home/miftah`, the gate still resolves this very plan set's root
to `/home/miftah/.worktrees/claude-commands/swarm-write-set-gate`.

**The old fallback was wrong for both layouts, so it is replaced, not kept.**
`dirname(dirname(abspath(index)))` gives `<wt>/docs` for `<wt>/docs/plans/X_PLAN.md` (one level
too deep) and the *parent of the worktree* for `<wt>/X_PLAN.md` (one level too shallow, outside
the tree entirely). The replacement is a **probe**: collect candidate roots in order of authority
— the git toplevel, then an `os.path.exists` walk for `.git` (for a machine with no git on PATH),
then the index's own directory and its first three ancestors — and return the first candidate
under which one of the phase-plan paths the index actually names exists.

Three properties make the probe safe rather than clever:

1. **It never invents an all-clear.** If *no* candidate resolves a single phase plan, it returns
   the first candidate (the git root when there is one) and `missing_plans` fires, so the gate
   still exits `1`. Test 9 (`test_missing_plans_still_exit_1`) pins this: probing must not turn
   "could not read" into a false `0`.
2. **The authoritative answer is tried first.** A git root that resolves plans always wins; the
   probe only speaks where git was silent or wrong.
3. **Depth 3 is bounded on purpose.** `/analyze` puts the index zero to two levels above the root;
   three gives one level of slack without reaching so far that an unrelated ancestor's
   `.workflows/` could answer for this plan set.

The index must therefore be parsed **before** the root is found — the root is derived *from* the
plan paths. That reordering is the only structural change to `build()`, and it is behaviour-safe:
`parse_index` has no filesystem dependency, and the "no phase table" error still returns first.

## Why the all-clear must be conditional (also R1)

This is inside R1, not a new requirement. The user's words name the sentence itself: the gate has
been returning "could not read" on every set the standard flow produces, *"while simultaneously
printing the reassuring line 'no file is written by two phases.'"* The root-finder removes the
**dominant cause** of `missing_plans`; it does not remove the false reassurance, which survives
for every other cause — a plan file genuinely absent, a typo'd `Plan` cell, a phase planned but
not yet written, a set being planned right now.

Reproduced live on **this** plan set while phase 2's plan file did not yet exist, with the root
fix fully in place:

```
phase plans not found (write set unknown, treated as empty):
  phase 2: .workflows/plan/swarm-write-set-gate/phase-2.md
  resolved against root: /home/miftah/.worktrees/claude-commands/swarm-write-set-gate

no file is written by two phases.
exit=1
```

Two phases of three were read; the third's write set is unknown and could collide with either.
The exit code is right and the English is a lie, and Step 3b shows a human the English. Phase 3
is building a hard-stop refusal that quotes this output, so the text has to stand on its own.

The same partiality applies to the other branch: `N of M shared files are written concurrently.`
is also computed over the phases that could be read, so it gets the same caveat. Both new forms
begin `INCOMPLETE:` and share no prefix with the clean sentence — a grep for the all-clear can
never match them. The clean path keeps today's exact bytes.

Measured: with the root fix in and the render guard removed, the harness still fails five
assertions. The guard is independently load-bearing, not a consequence of the root fix.

## Why most-severe-wins (R4)

Measured against today's code, with the root bug patched out so the collision is even visible:

```
phase 1  web/data/x.json  modify        <- the LOWER phase number
phase 2  web/data/x.json  regenerate

  [CONCURRENT] web/data/x.json  (modify)
      ISOLATE: separate worktrees merge cleanly IF the line regions are disjoint; ...
```

`classify('web/data/x.json', 'regenerate')` is `generated` and `classify(..., 'modify')` is
`modify`; `kind = next(...)` takes the first phase in index order, so the verdict is decided by
phase *numbering*. Renumber the phases and the same plan set reports ORDER. That is the live bug
the dead comprehension was reaching for, and invariant 6 says the most severe wins: BLOCK >
ORDER > ISOLATE. The replacement gathers the class from the **writing phases only** (`owners`
already excludes `read`) and takes the maximum of an explicit rank table.

```python
# --------------------------------------------------------------------- the repo root

# How far above the index to look when git cannot answer. `/analyze` files the index at
# `<root>/docs/plans/<SLUG>_PLAN.md` when `docs/` exists and at `<root>/<SLUG>_PLAN.md`
# when it does not, so the root is zero to two levels above the index's own directory.
# Three gives one level of slack without reaching so far that an unrelated ancestor's
# `.workflows/` can answer for this plan set.
ROOT_LOOKUP_DEPTH = 3


def _ancestors(start, depth=ROOT_LOOKUP_DEPTH):
    """`start` and its first `depth` ancestors, nearest first, no duplicates."""
    out, cur = [], start
    for _ in range(depth + 1):
        if cur not in out:
            out.append(cur)
        parent = os.path.dirname(cur)
        if parent == cur:                                 # reached "/"
            break
        cur = parent
    return out


def find_root(index_path, plans=()):
    """The directory the index's phase-plan paths are relative to.

    The old walk looked for a `.git` DIRECTORY, and in a linked worktree `.git` is a
    FILE -- a `gitdir:` pointer. `/analyze` always cuts a worktree, so the walk ran to
    `/` on every standard plan set and fell back to `dirname(dirname(index))`, which is
    wrong for both layouts `/analyze` produces. The gate then found no phase plans,
    reported every write set as empty, and still printed "no file is written by two
    phases" -- an all-clear over an analysis that never ran.

    Three answers are collected, in order of authority, and the first that actually
    resolves one of `plans` wins -- so a right-looking root that resolves nothing can
    never shadow one that does:

      1. `git rev-parse --show-toplevel`, run with cwd = the index's DIRECTORY, not the
         process cwd: a coordinator's cwd is often a different repo entirely. This is
         the house style (`swarm.py:161 main_worktree` asks git the same class of
         question) and it handles worktrees, submodules and `.git` files uniformly.
         `swarm.py`'s `git()` maps a missing binary and a non-zero exit alike to None,
         so no-git degrades instead of raising (invariant 4).
      2. an `os.path.exists` walk for `.git`, for a machine with no git on PATH.
      3. the index's own directory and its nearest ancestors, probed against the phase
         plan paths the index actually names -- the replacement for the old fallback,
         which was correct for neither layout and only ever worked by accident.
    """
    index_dir = os.path.dirname(os.path.abspath(index_path)) or os.getcwd()

    candidates = []
    top = git("rev-parse", "--show-toplevel", cwd=index_dir)
    if top and os.path.isdir(top):
        candidates.append(os.path.abspath(top))

    walk = index_dir
    while True:
        if os.path.exists(os.path.join(walk, ".git")):
            candidates.append(walk)
            break
        parent = os.path.dirname(walk)
        if parent == walk:
            break
        walk = parent

    candidates.extend(_ancestors(index_dir))

    ordered, seen = [], set()
    for cand in candidates:
        if cand not in seen:
            seen.add(cand)
            ordered.append(cand)

    relative = [p for p in plans if p and not os.path.isabs(p)]
    for cand in ordered:
        if any(os.path.exists(os.path.join(cand, p)) for p in relative):
            return cand
    return ordered[0] if ordered else index_dir


# ------------------------------------------------------------------------- severity

# Most severe first. When two phases declare one path with different actions the WORST
# class wins, never the first phase in index order (invariant 6: BLOCK > ORDER >
# ISOLATE). The old `kind = next(...)` took whichever phase was numbered lower, so a
# generated or binary path that a lower-numbered phase called `modify` was reported
# ISOLATE -- and a wrong ISOLATE on a database is the one error whose cost is rows that
# no longer exist. A rank table rather than a chain of ifs, so a class added later is
# one row here and one row in `_verdict`.
SEVERITY = {"binary": 40, "generated": 30, "modify": 20, "create": 10}

# A class this table has not heard of -- a later per-repo configuration may mint one --
# outranks `modify` but never reaches `binary`: never silently downgraded to ISOLATE,
# never falsely escalated to BLOCK.
SEVERITY_UNKNOWN = 25


def most_severe(kinds, default="modify"):
    """The worst class among the ways the writing phases declared one path.

    `read` is not a write and never participates: a path is only here because some
    phase writes it, and a third phase that merely reads it cannot soften the verdict.
    """
    ranked = sorted({k for k in kinds if k and k != "read"})
    if not ranked:
        return default
    return max(ranked, key=lambda k: SEVERITY.get(k, SEVERITY_UNKNOWN))

```

def build(index_path):
    meta, phases = parse_index(open(index_path, encoding="utf-8").read())
    if not phases:
        return {"error": f"{index_path} has no phase table"}

    # The plan paths in the index are repo-relative, so the root has to be found before
    # any of them can be opened -- and it is found FROM them, which is why the index is
    # parsed first now.
    repo = find_root(index_path, [p.get("plan") or "" for p in phases])

    writes, missing = {}, []
    for p in phases:
        p["files"] = {}
        plan = p.get("plan") or ""
        full = plan if os.path.isabs(plan) else os.path.join(repo, plan)
        if not plan or not os.path.exists(full):
            missing.append({"phase": p["n"], "plan": plan or "(none)"})
            continue
        for path, action in parse_files(open(full, encoding="utf-8").read()):
            kind = classify(path, action)
            p["files"][path] = kind
            if kind != "read":
                writes.setdefault(path, []).append(p["n"])

    dep_waves = waves({"phases": phases})
    wave_of = {}
    for w in dep_waves:
        for n in w.get("phases", []):
            wave_of[n] = w["wave"]

    by_n = {p["n"]: p for p in phases}
    collisions = []
    for path, owners in sorted(writes.items()):
        if len(owners) < 2:
            continue
        # Every way the WRITING phases declared this path, worst one wins -- never the
        # first phase in index order. `owners` holds writers only, so no `read` is here.
        kind = most_severe([by_n[owner]["files"].get(path) for owner in owners])
        by_wave = {}
        for n in owners:
            by_wave.setdefault(wave_of.get(n), []).append(n)
        concurrent = sorted(
            [sorted(v) for k, v in by_wave.items() if len(v) > 1], key=lambda g: g[0]
        )
        collisions.append({
            "path": path,
            "kind": kind,
            "written_by": sorted(owners),
            "waves": {str(k): sorted(v) for k, v in sorted(by_wave.items(), key=lambda kv: (kv[0] is None, kv[0]))},
            "concurrent": concurrent,
            "verdict": _verdict(kind, concurrent),
        })
    return {
        "slug": meta.get("slug"),
        "index": index_path,
        "root": repo,
        "phases": [{"n": p["n"], "title": p["title"], "depends_on": p["depends_on"],
                    "wave": wave_of.get(p["n"]),
                    "writes": sorted(f for f, k in p["files"].items() if k != "read")}
                   for p in phases],
        "dep_waves": [w.get("phases", w.get("cycle", [])) for w in dep_waves],
        "collisions": collisions,
        "missing_plans": missing,
    }

def render(g):
    if g.get("error"):
        return g["error"]
    out = [f"plan set: {g['slug']}   phases: {len(g['phases'])}",
           f"dependency waves: {' -> '.join('[' + ', '.join(map(str, w)) + ']' for w in g['dep_waves'])}",
           ""]
    out.append("write sets")
    for p in g["phases"]:
        out.append(f"  phase {p['n']} (wave {p['wave']}, depends on {p['depends_on'] or '-'}): "
                   f"{len(p['writes'])} files")
        for f in p["writes"]:
            out.append(f"      {f}")
    if g["missing_plans"]:
        out.append("")
        out.append("phase plans not found (write set unknown, treated as empty):")
        for m in g["missing_plans"]:
            out.append(f"  phase {m['phase']}: {m['plan']}")
        out.append(f"  resolved against root: {g.get('root')}")
    out.append("")
    # "no collision was FOUND" and "no collision EXISTS" are different statements, and
    # only the first is true when a write set is unknown. The old text asserted the
    # second unconditionally, so the gate printed an all-clear over an analysis that
    # never ran -- the reassuring sentence that let the worktree bug survive four real
    # plan sets. The clean sentence is kept byte-identical; the incomplete one shares
    # no prefix with it, so neither a reader nor a grep can mistake one for the other.
    unknown = len(g["missing_plans"])
    known = len(g["phases"]) - unknown
    if not g["collisions"]:
        if unknown:
            out.append(f"INCOMPLETE: no collision among the {known} of {len(g['phases'])} "
                       f"phases whose plan could be read. {unknown} write set"
                       f"{' is' if unknown == 1 else 's are'} unknown, so this is not "
                       f"an all-clear.")
        else:
            out.append("no file is written by two phases.")
        return "\n".join(out)
    out.append(f"shared files: {len(g['collisions'])}")
    for c in g["collisions"]:
        flag = "CONCURRENT" if c["concurrent"] else "sequential"
        out.append(f"  [{flag}] {c['path']}  ({c['kind']})")
        out.append(f"      written by phases {c['written_by']}, by wave: {c['waves']}")
        out.append(f"      {c['verdict']}")
    live = [c for c in g["collisions"] if c["concurrent"]]
    out.append("")
    out.append(f"{len(live)} of {len(g['collisions'])} shared files are written concurrently.")
    if unknown:
        # The same partiality, on the other branch: this count was computed over the
        # phases that could be read, and a phase whose plan is unknown may collide with
        # any of them.
        out.append(f"INCOMPLETE: computed over {known} of {len(g['phases'])} phases. "
                   f"{unknown} write set{' is' if unknown == 1 else 's are'} unknown, "
                   f"so there may be collisions this does not list.")
    return "\n".join(out)

**Impact:** the exit-1 case now reads as a failure instead of an all-clear, and says where it
looked. Phase 3's hard stop can quote this verbatim. No JSON consumer is affected — `--json`
never goes through `render()` — and `main()`'s exit codes are untouched (invariant 5): a missing
plan is still `1` even when a collision was also found among the plans that *could* be read,
which `test_missing_plan_caveats_the_collision_summary` pins explicitly.

### Step 5: Create the regression harness
**File:** `skills/swarm/tests/test_plan_graph.py` (new file, new directory `skills/swarm/tests/`)
**Change:** a self-contained, stdlib-only harness. This repo has no test runner, no lint and no
CI (CLAUDE.md), so it brings its own: a `eq`/`ok` collector in the same shape as
`swarm.py selftest()` (`swarm.py:1817`), a `@case` registry, and a driver that catches a raising
case instead of losing the run. Thirteen cases: the two linked-worktree layouts, the main
checkout, outside-any-repo, severity (fixture + unit table), clean, sequential, missing plans,
no phase table, and the three false-all-clear cases. Every fixture is built under `tempfile.mkdtemp()` and removed;
the module under test stays read-only (invariant 3).

Two design points worth not undoing:
- It imports `plan_graph` from **its own parent directory** and shells out to the
  `plan_graph.py` **beside it**. So `python3 ~/.claude/skills/swarm/tests/test_plan_graph.py`
  tests the *installed* copy — which is the one every swarm actually runs, and the one invariant
  2 requires the final assertion to be made against.
- Exit codes are checked by running the CLI as a **subprocess**, because the exit code is what
  Step 3b reads; structure is checked by calling `build()` directly; and the three
  false-all-clear cases assert on `render()`'s **text**, because the text is what Step 3b shows a
  human and what Phase 3's refusal will quote.
- `plan_set(root, index_rel, *phases, deps=None)` takes **N** phases, not two. The third
  false-all-clear case needs three. Phase 2 inherits a fixture that already generalises.

#!/usr/bin/env python3
"""Regression tests for the swarm write-set gate.

This repo has no test runner, no lint and no CI (CLAUDE.md), so the harness brings its
own: Python 3 standard library only, no pytest, run it directly.

    python3 skills/swarm/tests/test_plan_graph.py              # the repo copy
    python3 ~/.claude/skills/swarm/tests/test_plan_graph.py    # the INSTALLED copy

Both spellings matter. `sync.sh` COPIES rather than symlinks, so the installed copy is
the one every swarm actually runs and is the one a fix must finally be asserted
against. The harness imports `plan_graph` from its own parent directory and shells out
to the `plan_graph.py` beside it, so whichever tree it is run from is the tree it tests.

THE CASE THAT WAS NEVER COVERED is the linked worktree. `/analyze` always cuts one, and
in a worktree `.git` is a FILE, not a directory -- so the gate's root walk ran to `/`,
found no phase plans, reported every write set as empty, and printed "no file is
written by two phases" over a plan set that collided. Tests 1 and 2 build a real repo,
`git worktree add` a real linked worktree, put a real plan set inside, and assert the
gate finds the write sets and exits 2.

Each test builds its tree under tempfile.mkdtemp() and removes it; nothing is written
anywhere else. The module under test stays read-only (invariant 3).
"""

import os
import shutil
import subprocess
import sys
import tempfile

HERE = os.path.dirname(os.path.abspath(__file__))
SWARM = os.path.dirname(HERE)
sys.path.insert(0, SWARM)

import plan_graph  # noqa: E402

GATE = os.path.join(SWARM, "plan_graph.py")


# ------------------------------------------------------------------------- fixtures

INDEX_HEAD = """# Plan: Demo

**Slug:** demo
**Phases:** {n}
**Status:** planned

## Phases

| # | Title | Satisfies | Package | Files | Depends on | Difficulty | Plan | TaskID | Card |
|---|-------|-----------|---------|-------|-----------|------------|------|--------|------|
"""

INDEX_ROW = "| {n} | Phase {n} | R1 | `src` | {k} | {dep} | NORMAL | `{plan}` | — | — |\n"

INDEX_TAIL = "\n## Rollback\n"

PHASE = """# Phase {n}: {title}

## Files

| File | Action | What changes |
|---|---|---|
{rows}

## Verification

**Exit criteria:** it works.
"""


def write(path, text):
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "w", encoding="utf-8") as handle:
        handle.write(text)


def phase_plan(n, title, files):
    rows = "\n".join(f"| `{p}` | {a} | something |" for p, a in files)
    return PHASE.format(n=n, title=title, rows=rows)


def plan_set(root, index_rel, *phases, deps=None):
    """Write an N-phase plan set into `root`; return the absolute index path.

    `phases` is one `[(path, action)]` list per phase, in order. `deps` is an optional
    list of `Depends on` cell strings of the same length, defaulting to no dependency
    at all -- i.e. every phase in wave 0, which is what makes a shared path concurrent.
    """
    deps = deps or ["—"] * len(phases)
    rows = ""
    for i, files in enumerate(phases, 1):
        rel = f".workflows/plan/demo/phase-{i}.md"
        write(os.path.join(root, rel), phase_plan(i, f"Phase {i}", files))
        rows += INDEX_ROW.format(n=i, k=len(files), dep=deps[i - 1], plan=rel)
    index = os.path.join(root, index_rel)
    write(index, INDEX_HEAD.format(n=len(phases)) + rows + INDEX_TAIL)
    return index


SHARED = [("src/one.py", "modify"), ("src/shared.py", "modify")]
SHARED2 = [("src/two.py", "modify"), ("src/shared.py", "modify")]


# ------------------------------------------------------------------------------ git

GIT_ENV = dict(
    os.environ,
    GIT_CONFIG_GLOBAL=os.devnull,
    GIT_CONFIG_SYSTEM=os.devnull,
    GIT_AUTHOR_NAME="t", GIT_AUTHOR_EMAIL="t@t",
    GIT_COMMITTER_NAME="t", GIT_COMMITTER_EMAIL="t@t",
)


def git(*args, cwd=None):
    return subprocess.run(("git",) + args, cwd=cwd, env=GIT_ENV,
                          capture_output=True, text=True, timeout=30)


def have_git():
    try:
        return git("--version").returncode == 0
    except OSError:
        return False


def make_repo(root):
    """An initialised repo with one commit, so `git worktree add` has a base."""
    os.makedirs(root, exist_ok=True)
    git("init", "-q", cwd=root)
    write(os.path.join(root, "README.md"), "demo\n")
    git("add", "-A", cwd=root)
    git("commit", "-q", "-m", "init", cwd=root)
    return root


def add_worktree(repo, path, branch="feat"):
    out = git("worktree", "add", "-q", "-b", branch, path, cwd=repo)
    if out.returncode != 0:
        raise RuntimeError(f"git worktree add failed: {out.stderr}")
    return path

FAILURES = []
RUN = []


def eq(label, got, want):
    if got != want:
        FAILURES.append(f"{label}: got {got!r}, want {want!r}")


def ok(label, cond):
    if not cond:
        FAILURES.append(f"{label}: expected true")


def case(fn):
    RUN.append(fn)
    return fn


def gate_exit(index, cwd=None):
    """The CLI's exit code -- the thing the orchestrator's Step 3b actually reads."""
    out = subprocess.run([sys.executable, GATE, index], cwd=cwd,
                         capture_output=True, text=True, timeout=60)
    return out.returncode


def _real(path):
    """realpath, but None stays None -- so a module with no `root` key reads as None
    in the failure line instead of silently resolving to the process cwd."""
    return os.path.realpath(path) if path else None


def collision(graph, path):
    for c in graph.get("collisions", []):
        if c["path"] == path:
            return c
    return None

def _worktree_case(label, index_rel):
    tmp = tempfile.mkdtemp(prefix="pg-wt-")
    try:
        repo = make_repo(os.path.join(tmp, "repo"))
        wt = add_worktree(repo, os.path.join(tmp, "wt"))
        ok(f"{label}: .git is a file, not a directory",
           os.path.isfile(os.path.join(wt, ".git")))

        index = plan_set(wt, index_rel, SHARED, SHARED2)
        g = plan_graph.build(index)

        eq(f"{label}: root is the worktree", _real(g.get("root")),
           os.path.realpath(wt))
        eq(f"{label}: no plan went missing", g["missing_plans"], [])
        eq(f"{label}: phase 1 write set", g["phases"][0]["writes"],
           ["src/one.py", "src/shared.py"])
        eq(f"{label}: phase 2 write set", g["phases"][1]["writes"],
           ["src/shared.py", "src/two.py"])

        hit = collision(g, "src/shared.py")
        ok(f"{label}: the shared file is reported", hit is not None)
        if hit:
            eq(f"{label}: both phases own it", hit["written_by"], [1, 2])
            eq(f"{label}: they are concurrent", hit["concurrent"], [[1, 2]])
            ok(f"{label}: verdict is ISOLATE", hit["verdict"].startswith("ISOLATE"))

        eq(f"{label}: exits 2, not 1", gate_exit(index), 2)
    finally:
        shutil.rmtree(tmp, ignore_errors=True)

              file=sys.stderr)

            fn()

            print(f"FAIL {line}", file=sys.stderr)

The `./sync.sh` is not optional and is the step that gets forgotten. A revert without it leaves
the *fixed* code installed in `~/.claude/` and the *reverted* code in the repo — the exact drift
CLAUDE.md warns about, and the worst version of it, because the running swarm would then be using
code that no longer exists anywhere in git. `sync.sh` copies rather than deletes, so the stale
`~/.claude/skills/swarm/tests/` directory survives the copy and must be removed by hand:
`rm -rf ~/.claude/skills/swarm/tests`.

**Ordering constraint:** Phase 2 also edits `plan_graph.py`. Once Phase 2 has landed, this phase
cannot be reverted alone — revert Phase 2 first (the index's Rollback section says the same).
